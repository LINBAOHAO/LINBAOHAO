# 夜谈

一个夜里还能说话的聊天站。五位值夜的人各自有性格，你发出去的每一句都由语言模型当场回复，不是写好的台词。

## 本地运行

```bash
npm install
npm run dev
```

构建：

```bash
npm run build
```

## 怎么聊

1. 左边选一个人：书店夜班的晚棠、刚下班的江澄、电台主播阿梨、在路上的周野、修表的老沈。
2. 直接打字，或点开场白下面的一句。
3. 对话留在这台浏览器里。换人或刷新都还在。
4. 「重新开始」只清空当前这个人。

免费线路走公开模型，不用密钥。它比较忙的时候会请你等大约半分钟。想聊得更顺，打开设置，填一条 OpenAI 兼容接口（地址、密钥、模型名）。密钥只存在本地。
